Crear cuentas de Docente y Administrador

Desde este módulo el administrador puede registrar nuevos docentes y también crear otros administradores del sistema.

El alumno se gestiona desde registro o carga académica; este módulo es para personal autorizado.

Crear nuevo reto

Desde este módulo el administrador puede agregar retos nuevos. Al guardar, el reto se registra en PostgreSQL y aparece automáticamente en el panel del alumno.

Cada línea será un bloque. El primer bloque tiene índice 0, el segundo índice 1, y así sucesivamente.
Usa los índices de los bloques separados por coma.
